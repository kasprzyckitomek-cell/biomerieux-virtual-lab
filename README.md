# Wirtualne Laboratorium – symulator aparatów bioMérieux

Edukacyjna gra przeglądarkowa: chodzisz po laboratorium jako diagnosta, przyjmujesz próbki, posiewasz, przygotowujesz zawiesiny i uruchamiasz aparaty (VITEK 2 Compact, VITEK MS PRIME, BacT/ALERT VIRTUO, BIOFIRE FILMARRAY TORCH / 2.0 / SPOTFIRE, VIDAS 3, mini VIDAS, DENSICHEK, PREVI Isola, PREVI Color Gram, ETEST, API 20 E, MYLA, TEMPO, GENE-UP).

Uruchomienie: `npm start` (Node.js ≥ 18, bez zależności). Port z `PORT`.

Projekt nieoficjalny, niepowiązany z bioMérieux SA. Wartości demonstracyjne – nie do użytku diagnostycznego.
